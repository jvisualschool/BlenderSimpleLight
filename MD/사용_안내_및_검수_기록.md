## 1. 폴더 구조와 결과물

- `py-json/simple_light/` : Blender 5.3 확장 애드온 소스 패키지
  - `blender_manifest.toml` : 확장 매니페스트 정보 (`Simple Light`, `1.0.0`, `Jinho Jung`)
  - `__init__.py` : 썸네일 미리보기 선택기(`bpy.utils.previews`), 피사체 적용/교체/제거 오퍼레이터, N-패널 UI
  - `builder.py` : 22개 조명 레시피 및 소품(블라인드, 국소 볼륨과 가림판, 창문, 프랙티컬 램프, 촛불 애니메이션) 생성기 및 크기 보정 엔진
  - `presets.json` : 22개 조명 레시피, 관찰 포인트, 파일 경로 통합 데이터
  - `icons/` : 1200×1200 원본 렌더에서 생성한 256×256 PNG 애드온 썸네일 22장
- `py-json/simple_light-1.0.0.zip` : `Blender --command extension build` 및 `validate`를 통과한 배포용 확장 설치 파일
- `blend/suzanne_simple_light.blend` : 편집 가능한 기준 수잔 비교 장면 (70mm 카메라, Subdivision 2, 중성 회색 무광 재질, AgX 색 관리 고정)
- `Preview/` : 오프라인 HTML 미리보기 갤러리 및 촬영 원본 자산
  - `index.html` : 인터넷 연결 없이 로컬에서 바로 여는 22종 조명 갤러리 및 두 조명 비교 슬라이더
  - `images/` : 1200×1200 PNG 마스터 렌더 22장, WebP 22장, `18_candlelight.mp4` (1~48프레임 2초 반복 영상)
  - `layouts/` : 실제 Blender 3D Viewport 창에서 사선 위 구도로 촬영한 1200×900 PNG 및 WebP 조명 배치 캡처 22장

## 2. Blender 5.3 설치 및 사용 방법

### 2.1 ZIP 패키지 설치
1. Blender 5.3 이상을 실행하고 상단 메뉴에서 **Edit → Preferences → Get Extensions** (또는 **Add-ons**) 탭을 엽니다.
2. 우측 상단 메뉴(`⌄`)에서 **Install from Disk...**를 선택하고 `py-json/simple_light-1.0.0.zip` 파일을 지정합니다.
3. 설치 후 **Simple Light** 애드온이 체크(활성화)되어 있는지 확인합니다.

### 2.2 피사체에 조명 세트 적용 및 교체
1. 3D Viewport에서 조명을 비출 피사체 오브젝트를 선택합니다.
2. 키보드 `N`을 눌러 우측 사이드바에서 **Simple Light** 탭을 엽니다.
3. **1. 프리셋 선택** 영역의 큰 수잔 썸네일 아이콘 뷰를 클릭해 01~22번 중 원하는 조명을 선택하고 한 줄 관찰 포인트를 확인합니다.
4. **2. 피사체 및 촬영 방향**에서 대상(`오브젝트` 또는 `컬렉션`)과 정면 기준(`활성 카메라` 또는 `현재 뷰`)을 고릅니다.
   - 기존 장면에 다른 조명이나 월드 환경광이 켜져 있으면 패널에 안내 문구가 표시됩니다.
   - **비교 모드 (기존 조명 격리)**를 켜면 기존 조명과 월드 강도를 스냅샷으로 저장한 뒤 잠시 끄고 현재 프리셋만 격리해 볼 수 있습니다. 비교 모드를 끄거나 세트를 제거하면 원래 상태로 복구됩니다.
5. **적용 / 교체** 버튼을 누르면 피사체 중심과 폭($D$)을 계산하여 기준 수잔 폭($D_0 = 1.6406\text{ m}$) 대비 비율 $k = D / D_0$에 맞춰 광원 거리, 크기($k$배), 유한 광원 출력($k^2$배), 국소 볼륨 밀도($1/k$배)가 자동 설치됩니다.
6. 다른 프리셋을 고른 뒤 **적용 / 교체**를 다시 누르면 방금 설치한 세트 ID(`simple_light_rig_id`)가 소유한 광원과 소품만 깔끔하게 교체되며, 사용자가 만든 기존 오브젝트와 조명은 보존됩니다.

## 3. 렌더 조건 및 보정 수치 기록

### 3.1 공통 촬영 기록 (`py-json/render_metadata.json`)
- **Blender 버전** : Blender 5.3.0 (macOS Darwin, build hash `02f0899d78e3`)
- **렌더 엔진 / 장치** : Cycles / CPU (공통 검증 장치)
- **샘플 및 노이즈 제거** : 최종 렌더 128 samples, Denoise 활성화
- **색 관리 (Color Management)** : View Transform `AgX`, Look `None`, Exposure `0.0`, Gamma `1.0` 고정
- **카메라** : 위치 `(0, -5, 1.7)`, 타깃 `(0, 0, 1.2)`, 초점거리 `70 mm`, 센서 폭 `36 mm`
- **배치 캡처 (`py-json/layout_capture_metadata.json`)** : 헤드리스 렌더와 분리하여 실제 Blender GUI 창의 3D Viewport OpenGL 캡처(`1200 × 900`)로 광원 이름, 조사 방향, 소품(슬랫, 가림판, 창틀, 램프, 촛불)을 기록

### 3.2 수잔 구조에 맞춰 보정 및 확정한 설정값
1. **05 하드 라이트 vs 06 소프트 라이트**
   - 두 프리셋 모두 광원 중심을 `(-2, -3, 3.5)`에 고정하고 발광면 크기만 `0.08 m`와 `2.0 m`로 구분했습니다.
   - 발광면 확대로 인한 밝은 쪽 볼의 조도 감소를 보정하기 위해 `06_soft`의 기본 출력을 `540 W`(`energy_compensation: 1.08`)로 확정했습니다.
2. **08 렘브란트 (Rembrandt)**
   - 수잔의 돌출된 주둥이와 깊은 눈구멍 구조에서 그늘진 오른쪽 눈 아래 볼에 렘브란트 삼각형이 맺히도록 문서의 탐색 범위(수평각 35~60도, 높이 2.6~3.6 m) 안에서 수평각 `58도`, 높이 `3.6 m` (`[-1.357, -0.848, 3.6]`, 크기 `0.12 m`, 출력 `260 W`, 필 `15 W`)로 확정했습니다.
3. **03 실루엣 vs 12 림 라이트**
   - `03_silhouette`은 밝은 배경판(`y = 2.4 m`)을 `800 W`로 비춰 배경 반사광이 수잔 정면에 닿지 않게 간격을 확보했습니다.
   - `12_rim_light`은 어두운 배경 앞에서 뒤쪽 사선 직사각형 Area(`0.25 × 2.0 m`)가 바닥을 하얗게 비추지 않도록 카메라에 보이지 않는 무광 암막 차광판(`RIM_FLOOR_BLOCKER`)을 추가해 어두운 배경 속 귀와 머리의 밝은 윤곽선만 선명하게 남겼습니다.
4. **14~18 소품 프리셋**
   - `14_venetian_blinds` : 광원과 타깃 중간에 14개 차광 슬랫(간격 `0.16 m`, 광축 회전 `20도`)을 배치해 얼굴과 배경에 평행 줄무늬 그림자를 형성했습니다.
   - `15_volumetric` : `6 × 6 × 4 m` 국소 볼륨 박스(`Principled Volume`, 밀도 `0.035`, 이방성 `0.45`)와 후방 스포트라이트 앞 가림판으로 빈 공간의 빛줄기(God rays)를 구현했습니다.
   - `16_motivated` : `x = -1.8 m`의 창문 개구부(`1.5 × 2.0 m`)와 십자 창살을 통과한 창밖 조명이 볼과 배경에 창틀 그림자를 맺히게 했습니다.
   - `17_practical` : 화면 왼쪽에 전구 발광체, 갓, 스탠드로 구성된 램프를 배치해 램프와 볼의 밝기, 바닥 빛 자국이 자연스럽게 이어지게 했습니다.
   - `18_candlelight` : 시드 `18`의 난수 생성기로 1~48프레임(4프레임 간격, 49프레임=1프레임 동일값, 선형 보간 및 Cycles 반복) 동안 광원 출력과 불꽃 발광 강도가 함께 흔들리도록 키프레임을 기록했습니다.
